# SmartDesk - מערכת חכמה לניהול וניתוב פניות שירות

מערכת Web לניהול פניות שירות לקוחות מרובת חברות מבוססת בינה מלאכותית (AI).

## מבנה הפרויקט
* `/frontend` - ממשק המשתמש (Client)
* `/backend` - שרת ה-API והחיבור למסד הנתונים ולמודל ה-AI

## הוראות הרצה מקומית (Docker)

1. יש לוודא כי מותקן במחשב **Docker Desktop** והוא פועל.
2. יש לשכפל (Clone) את המאגר למחשב המקומי:
   ```bash
   git clone https://github.com
   cd SmartDesk
   ```
3. יש ליצור קובץ בשם `.env` בתיקייה הראשית (או בתיקיית השרת בהתאם להגדרות) ולהזין בו את מפתחות הגישה למסד הנתונים (Supabase) ול-API של מודל ה-AI. *(קובץ זה מוחרג מ-Git מטעמי אבטחה)*.
4. להרצת כלל רכיבי המערכת (Frontend ו-Backend) יש להריץ בטרמינל:
   ```bash
   docker compose up --build
   ```
5. לאחר סיום הבנייה, המערכת תהיה זמינה בדפדפן.
